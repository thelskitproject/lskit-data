# LSKit Data

教室二维码记录，保存在 `checkin-codes.json`。

## 数据格式

每条记录包含四个字段：

| 字段 | 内容 |
| --- | --- |
| `buildingName` | 教学楼名称 |
| `roomName` | 房间名称，未知时为 `null` |
| `roomNumber` | 房间号，按字符串保存 |
| `matrix` | 二维码黑白模块矩阵的 Base64 |

矩阵按行排列，以每字节最高位优先打包，末尾补零。矩阵保留原二维码的模块排列，边长从解码后的字节数推导。

## 新增记录

在网站点击「提交教室记录」，跳转到已填写好的 Issue，登录 GitHub 后点击 Create issue。手动提交时，在「教室记录」中粘贴一条 JSON，保留 `[新增教室]` 标题前缀。请核对教学楼、房间名称、房间号和二维码图案。

通过校验的记录会生成 PR，由维护者审核后收录。同一教学楼和房间号不会自动覆盖已有记录。
